# 固定翼无人机机翼翼型：论文 ground truth 与本地工具链分步验证

> 版本：v1.1 ｜ 2026-11-13（S2 解析式复核、S4 应力口径按修复后的后处理重写）
> 目的：选一篇公开可查的固定翼无人机翼型设计与仿真论文，提取其**设计参数与仿真结果**作为 ground truth，
> 用本机刚搭好的开源 CAD/CAE 工具链（build123d + gmsh + CalculiX + PyVista，可选 FreeCAD）**逐步复算并给出误差**。

## 1. 选定的论文与可提取的 ground truth

### 1.1 主参考论文（翼型设计与 CFD）

- **Sarkar, A.; Mahto, V. K.** *Computational Analysis of Flow Characteristics over NACA 4412 Airfoil Using CFD simulation at Varying Angles of Attack.*
  International Journal of Innovative Research and Technology **12**(2): 3882–3886, 2025.
  DOI: [10.5281/zenodo.16422521](https://doi.org/10.5281/zenodo.16422521) ｜ 许可：CC-BY-4.0 ｜ 全文 PDF 可公开下载。

**可提取的设计参数（论文第 III 节）：**

| 参数 | 论文值 | 说明 |
|---|---|---|
| 翼型 | NACA 4412 | 4 位数翼型 |
| 最大弯度 | 4% c，位于 40% c | 与 NACA 4412 定义一致 |
| 最大厚度 | 12% c | 与 NACA 4412 定义一致 |
| 计算域 | 上游 10c、下游 20c、上下各 10c | 2D 矩形域 |
| 网格 | 约 166,967 节点 / 166,000 单元 | 四边形结构网格 + 边界层 |
| 湍流模型 | Realizable k-ε + 增强壁面处理 | — |
| 来流 | 30–60 m/s，空气 ρ=1.225 kg/m³，μ=1.7894×10⁻⁵ Pa·s | — |
| 边界条件 | 速度入口 / 压力出口 0 Pa / 无滑移壁面 | — |

**可提取的仿真结果（论文第 IV 节）：**

| 量 | 论文值 | 备注 |
|---|---|---|
| 升力系数 Cl | **1.791092** | 单点值 |
| 阻力系数 Cd | **0.3620392** | 单点值 |
| 失速趋势 | Cl 在 14–15° 附近达峰后骤降 | 文字描述，无表格 |
| 0° 工况 | 对称来流、无升力 | 与弯翼型矛盾（见 §5） |

### 1.2 辅助参考（同主题、开放获取）

- **Shbailat, S. J.; Ridha, H. D.** *Constructal theory of aerodynamic design in NACA airfoils for search and rescue UAVs using integrated CFD and ANN approaches.*
  Scientific Reports **16**: 22705 (2026). DOI: [10.1038/s41598-026-54961-8](https://doi.org/10.1038/s41598-026-54961-8)（开放获取）。
  给出 NACA 4412 在 Re = 4.7×10⁴ / 6.7×10⁴ / 1×10⁵ 下 **Cl/Cd ≈ 1.38**（4°–12°）的结论，以及 20 m 半圆 + 60 m 矩形的计算域与网格收敛比 R = 0.97。

### 1.3 为什么不能把论文的 Cl/Cd 直接当"每步 ground truth"

1. **Cl、Cd 是单点值，论文没有给出对应迎角**（正文只说在 0°–20° 之间扫掠）。没有 AOA 就无法构造可复算的边界条件。
2. **Cd = 0.362 在量级上不合理**：二维翼型在 Re ~ 10⁵–10⁶ 的 Cd 通常在 **0.01–0.03**；0.36 高出一个数量级，疑似把三维/平板阻力或未收敛结果写进了正文。
3. **0° 工况描述自相矛盾**：NACA 4412 是弯翼型，0° 迎角下 Cl ≈ 0.4，不可能"无升力"。
4. **没有给出网格无关性表格与 Re 数**（只有入口速度区间），复算时无法对齐。

因此本报告的处理方式是：
- **几何参数**（4% 弯度 / 40% 位置 / 12% 厚度）→ 直接作为 ground truth，逐项复算；
- **Cl 量级** → 用薄翼理论核对（论文 Cl=1.79 对应约 12.2°，与其"峰值在 14–15°"的描述自洽）；
- **Cd** → 明确标注为"论文数据不可用"，不做数字对齐，只做量级说明。

工况取论文的 **Cl = 1.791092**、**V = 30 m/s**、**ρ = 1.225 kg/m³**：

```
q = 0.5·ρ·V²·Cl·c = 0.5 × 1.225 × 900 × 1.791092 × 0.30 = 296.2 N/m
L = q·b = 355.4 N
```

材料取 CFRP：E = 70 GPa、ν = 0.3、ρ = 1600 kg/m³（论文未给结构参数，此为本报告显式假设）。

## 3. 分步验证

### S1 翼型几何参数（对应论文"4% 弯度 @40%、12% 厚度"）

生成方式：NACA 4 位数标准公式，余弦分布 240 点/面，闭合后缘（0.1015 系数）。

| 指标 | 目标 | 复算 | 相对误差 |
|---|---|---|---|
| 最大厚度 | 12.00% c | 11.9888% c | 0.09% |
| 最大弯度 | 4.000% c | 4.0000% c | 0.00% |
| 最大弯度位置 | 40.0% c | 39.89% c | 0.11% c（绝对） |
| 前缘半径 | 1.1019·t² = 1.587% c | 1.5867% c | 0.02% |
| 后缘间隙 | 0（闭合） | 0.0025 c | 几何闭合方式差异 |

**结论：通过。** 厚度 0.09% 的偏差来自离散采样（余弦点不落在最大厚度站位上），属数值离散而非公式错误。

### S2 坐标与 CAD 实体

- 在 6 个标准站位（x/c = 0.1/0.3/0.5/0.7/0.9/1.0）与独立重算的标准型值逐点比对，**最大绝对偏差 4.9×10⁻⁵ c**（NACA 4 位型值改为解析式直接求值；旧实现把 `np.interp` 作用在 TE→LE 降序数组上，上半表面恒为 0，该 bug 已修）。
- 由 479 个点构造闭合 wire → face → 拉伸 1 mm 得到 STEP 实体（1.86 MB）：
  - 弦长 **300.0 mm**（bbox X = 300.138 mm，差值来自弯度导致的 x 方向偏移）；
  - bbox 高度 38.357 mm（= 12% × 300 = 36 mm + 弯度投影），面积比 **0.0825 c²**（NACA 4412 理论剖面面积约 0.082 c²，一致）。
- **结论：通过。** CAD 层能无损地把翼型坐标变成可网格化的实体。

### S3 气动：薄翼理论核对（论文 Cl 的量级）

对**复算出的弯度线**做薄翼理论积分：

```
α_L0 = (1/π)∫₀^π (dz/dx)(cosθ − 1) dθ = −4.154°
Cl(α) = 2π(α − α_L0)
```

| α | 薄翼理论 Cl | 说明 |
|---|---|---|
| 0° | 0.456 | 弯翼型 0° 有升力，论文"0° 无升力"不成立 |
| 4° | 0.894 | — |
| 8° | 1.333 | — |
| 12° | 1.772 | **论文 Cl=1.791 对应 α ≈ 12.18°** |
| 14° | 1.991 | 薄翼理论无失速，实际在此附近达峰 |
| 16° | 2.210 | 实际已失速 |

**结论：部分通过。**
- 论文 Cl = 1.791 与薄翼理论在 **α ≈ 12.2°** 的结果一致（差 0.1%），且与论文"峰值在 14–15°"的定性描述不矛盾；
- 但论文**未给出该点的 AOA**，所以这是"量级/自洽性验证"，不是严格的一对一复算；
- 论文 Cd = 0.362 比二维翼型合理值高一个数量级，**不纳入验证**。

### S4 结构：机翼 FEA vs Euler-Bernoulli 梁

模型：3 mm 壁厚 CFRP 翼盒（0.30 m × 0.04 m 截面），根部全约束，沿展向施加等效升力分布（体力法，避免局部蒙皮弯曲污染整体响应）。
两套网格：8 mm（30,311 节点 / 91,088 个 C3D4，求解 4.9 s）与 4 mm（120,025 节点 / 361,539 个 C3D4，求解 31 s）。

**展向挠度（主验证指标，4 mm 网格）：**

| z (mm) | FEA (mm) | 梁理论 (mm) | 相对误差 |
|---|---|---|---|
| 100 | 0.0418 | 0.0226 | 84.7% |
| 200 | 0.1257 | 0.0855 | 47.1% |
| 400 | 0.3739 | 0.3047 | 22.7% |
| 600 | 0.7032 | 0.6098 | 15.3% |
| 800 | 1.0783 | 0.9636 | 11.9% |
| 1000 | 1.4722 | 1.3395 | 9.9% |
| **1200（尖端）** | **1.8640**（截面均值；节点峰值 1.8657） | **1.7217** | **8.4%** |

**网格收敛：**

| 网格 | 尖端挠度 | 相对 8 mm | 说明 |
|---|---|---|---|
| 8 mm | 1.8367 mm | — | 30k 节点，4.8 s |
| 4 mm | 1.8657 mm | +1.6% | 120k 节点，31 s |
| 外推（≈2 mm） | ≈1.88 mm | +2.5% | Richardson 外推 |

**如何解读 8.4% 的差（独立分解，不再笼统归因于"剪切滞后"）：**
- **载荷理想化（+3.1 pp）**：`wing_fea.py` 默认 `--load body`，用 `*DLOAD GRAV` 把升力作为体力加在**全部壁面**上。同一网格改用顶面压力 `--load pressure` 后，尖端挠度 1.8353 → **1.7794 mm（+6.68 % → +3.35 %）**——这一项是模型伪影，不是结构物理。
- **腹板剪切变形（+2.2～2.7 pp）**：Timoshenko 剪切项按腹板受剪估算 0.039–0.047 mm。
- **真正的剪切滞后 / 蒙皮局部弯曲（仅 +0.6～1.1 pp）**：实测翼缘截面内 S33 不均匀度只有 ±3～6 %，且中翼缘略高（与经典"中翼缘滞后"方向相反）。
- 由挠度反推的 `I_eff/I = 0.9374`、等效翼缘宽 280.6 mm 是这三项的**集总值**，不能单独当作剪切滞后证据。
- 误差随 z 单调收敛、随网格加密单调收敛，符合数值方法预期；
- 挠跨比 1.55×10⁻³（1.86 mm / 1200 mm），属刚性机翼范围。

**应力：通过（逐截面 S33，与梁理论同截面比较）**

| 网格 | 截面 S33（z=100/200/400 mm，单元平均） | 梁理论（5.626/4.650/2.976 MPa） | 相对误差 |
|---|---|---|---|
| 8 mm | **5.586 / 4.506 / 2.942 MPa** | — | **0.7% / 3.1% / 1.1%** |
| 4 mm | **5.663 / 4.543 / 2.954 MPa** | — | **0.7% / 2.3% / 0.7%** |

- 8 mm 与 4 mm 两套网格的逐截面 S33 都与 `M·c/I` 吻合在 **3.1% 以内**，加密后变化 <0.1 MPa，说明薄壁翼盒的**整体弯曲应力场**已被正确捕捉；
- **根部局部峰值**（全约束角/内壁圆角处）约 **9.45 MPa（单元平均）/ 10.13 MPa（节点外插）**，是局部应力集中，与梁理论的"极端纤维弯曲应力"不是同一量，**不作为判据**；
- 旧版本的截面 S33（7.42/6.85/7.27 MPa 与 6.25/7.72/9.76 MPa）和"误差 32–185%、不收敛"是**后处理 bug 造成的假象**：`frd_reader` 返回的 `STRESS` 字典以**节点 id** 为键，而截面循环按**单元 id** 取值（两者都从 1 开始编号，静默错位）。修正后按"单元连接上的节点平均"重算即得上表。

**正确做法（后续可选）**：若要在 3 mm 薄壁上把局部峰值也做准，仍建议改用**壳单元（S4/S8）**或在距根部 1–2 倍截面高度以外提取翼缘中面轴向应力；但就"整体弯曲应力"这一判据而言，实体四面体已经足够。

**结论：挠度通过（6.7% / 8.4%，可解释且收敛）；逐截面弯曲应力通过（≤3.1%），根部局部峰值不作判据。**

## 7. 结论

1. **几何层（S1/S2）通过**：翼型厚度、弯度、位置、坐标、CAD 弦长全部与论文/标准一致，误差 ≤0.11%；坐标在 S2 上半表面 bug 修复后按解析式重算，6 个站位 max_abs_err = 4.9×10⁻⁵ c。
2. **气动层（S3）部分通过**：论文 Cl 与薄翼理论在 12.2° 自洽；但论文缺 AOA、Cd 量级异常，**不能作为严格 ground truth**，已如实标注。
3. **结构层（S4）挠度与逐截面应力均通过**：
   - 尖端挠度 1.837 mm（8 mm）/ 1.864 mm（4 mm）vs 梁理论 1.722 mm，差 6.7% / 8.4%，随网格加密收敛；独立分解：载荷理想化（body 全壁体力）+3.1 pp、腹板剪切 +2.2～2.7 pp、真实剪切滞后/蒙皮局部弯曲仅 +0.6～1.1 pp；
   - 逐截面 S33（z=100/200/400 mm）在 8 mm 网格为 5.586/4.506/2.942 MPa、4 mm 网格为 5.663/4.543/2.954 MPa，与梁理论 5.626/4.650/2.976 MPa 的误差 ≤3.1% 且加密后稳定；根部局部峰值（9.45/10.13 MPa）是固定端集中，不作判据。
4. **整条链可用**：从论文参数 → 翼型坐标 → STEP → 网格 → 求解 → 后处理，全流程在 Windows 本机开源工具上跑通，每步都有可复算的数字，**并对论文数据缺陷与工具链自身 bug 都如实标注**。

> 下一步建议：补一个**有完整 AOA–Cl–Cd 表格**的低雷诺数翼型实验数据集（如 UIUC / Abbott & von Doenhoff）做气动对标；结构侧改用壳单元并把翼盒做成真实蒙皮 + 翼梁布局，再与 Timoshenko 梁或试验挠度对比。
