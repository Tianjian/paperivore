# 电磁学：轴向磁通永磁电机（AFPM）设计与仿真验证

> 版本：v1.1 ｜ 2026-11-13（双转子磁路、周期边界与 flux 口径修正）
> 目标：用一篇 AFPM 设计/实测论文的参数，验证并扩展本地 CAE 工具链的**电磁场**能力，输出 3D/2D 设计与仿真结果。

## 0. 结论速览

| 项目 | 论文/实测 | 本地计算 | 偏差 | 判定 |
|---|---|---|---|---|
| 极槽/尺寸 | 5 对极、9 槽、OD 19 mm、ID 7 mm、气隙 0.25 mm、PCB 6 mm | 完全复现 | — | ✅ |
| 气隙磁密 $B_g$ | 论文未给 | 双转子 1-D 磁路 **0.3093 T**（旧单转子公式 0.179 T 偏低 42 %）／2D FEA **0.3766 T** | 2D 比 1-D 磁路高 **21.8 %** | ⚠️ 见 §4.1 |
| 转矩常数 $K_t$ | **32.0 mNm/A**（实测） | 表 I 匝数 216 + 1-D 磁路 = **12.28 mNm/A**；+ FEA 磁密 = **14.95 mNm/A** | **−61.6 % / −53.3 %** | ❌ 参数不自洽 |
| 反推有效匝数 | — | 要得到 32 mNm/A 需 **$N_{ph}\approx563$（磁路）/ 462（FEA）** | 表 I 推出（推断）216 | 论文缺项 |
| 相电阻 $R$ | **4.70 Ω**（实测） | 按 0.36 mm × 0.06 mm 铜箔几何 = **2.84 Ω** | −40 % | ⚠️ 端接/过孔未计 |

**一句话：几何完全复现；磁路改为双转子（TORUS）拓扑后，1-D 磁路 0.3093 T 与 2D FEA 0.3766 T 相差 +21.8%（旧文"24 %"是另一基准，且旧单转子公式本身偏低 42%）；但用论文表 I 的（推断）匝数 216 只能算出 12.3 mNm/A（磁路）/ 15.0 mNm/A（FEA 磁密），与实测 32 mNm/A 差 62 % / 53 %——要闭合需约 563 / 462 匝。论文仍缺磁钢厚度、Br 与绕组串并联的明确定义，这一点如实标为"未通过"，没有用拟合去凑。**

## 1. 论文与参数提取

**论文**：J. Wang, Q. Xie, J. Han, Y. Zhang, C. G. Atkeson, A. Gupta, D. Pathak, Y. Bisk,
*High Torque Density PCB Axial Flux Permanent Magnet Motor for Micro Robots*,
**arXiv:2509.23561**（开放获取）。

### 1.1 表 I — 设计参数（全部可复现）

| 参数 | 值 |
|---|---|
| 极对数 | 5（10 极） |
| 虚拟槽数 | 9 |
| 外径 / 内径 | 19 mm / 7.0 mm |
| 气隙（轴向） | 0.25 mm |
| PCB 定子厚度 | 6.0 mm |
| PCB 单层数 | 48 |
| 每线圈匝数 | 3 |
| 并联支路 | 2 |
| 走线宽度 | 0.36 mm |

| 额定电压 | 24–48 V |

> 表 I 的 "Turns of coil / Number of PCBs connected in series = 3" 是有歧义的表述；本报告按"每线圈 3 匝 × 48 层，每相 2 并联"推得 $N_{ph}=48\times3\times3/2=216$，**这是推断，不是论文的明确值**。

|---|---|

### 1.3 论文**没有**给的关键量（后续验证的瓶颈）

- 磁钢厚度 $h_m$、剩磁 $B_r$、牌号
- 绕组"48 层 × 3 匝 × 2 并联"到"每相串联匝数"的确切换算
- 磁钢形状（扇形/矩形）、极弧系数
- 铁芯材料与厚度

本报告取 $h_m=1.0$ mm、$B_r=1.3$ T、$\mu_r=1.05$、铁芯 $\mu_r=1000$ 作为**显式假设**并在结果中标注。

## 2. 工具链新增能力：自研 2D 磁静场求解器

原工具链（build123d / gmsh / CalculiX / PyVista）**没有电磁求解器**。本轮新增：

- **公式**：磁标量势 $\nabla\cdot(\mu\nabla\varphi)=\nabla\cdot(\mu_0\mathbf M)$，$B=-\mu\nabla\varphi+\mu_0\mathbf M$
- **离散**：线性三角形单元，标准刚度阵 $\int\mu\nabla N_i\cdot\nabla N_j$，磁钢以 $\int\mu_0\mathbf M\cdot\nabla N_i$ 进入右端
- **边界**：切向周期（极距）、PCB 中面 Neumann 对称、外表面 $\varphi=0$
- **实现**：numpy 装配 + scipy 稀疏求解，网格 160×120（19,200 个四边形 → 38,400 个三角形单元），求解 < 2 s
- **域**：平均半径处展开成"切向 x — 轴向 y"的平面，一个极距

结果：气隙平均磁密 $B_g = 0.3766$ T（周期边界修正后），双转子 1-D 磁路 0.3093 T。

> **周期边界 bug（2026-11 修复）**：旧版 `solve_2d` 把右边界直接钳成 $\varphi=0$，而不是与左边界相等——$\varphi(0)-\varphi(L_x)\approx819$ A，两个半极区的 $|B_y|$ 相差 2.9 倍，**场图不是周期的，不能用作定量依据**。修复方式是在装配前把 slave 自由度合并到 master；修复后 $B_g$ 仅变 **−0.6 %**（0.3790 → 0.3766 T）：标量结论不变，但**修复前的场图不可信**；当前 `viz/field_2d.png` 等图已用修复后版本重绘。

## 3. 解析磁路模型

采用**双转子（TORUS）拓扑**：两个转子磁钢串联，驱动磁通从两侧穿过同一块 PCB，回路里有 **2 个磁钢 + 2 个气隙 + 1 块 PCB**：

$$B_g=\frac{2B_r h_m}{2h_m/\mu_r+2g+t_{PCB}},\qquad 2g+t_{PCB}=2\times0.25+6.0=6.5\ \text{mm}$$

$h_m=1$ mm、$B_r=1.3$ T、$\mu_r=1.05$ ⇒ $B_g=0.3093$ T。

> 旧版用的是**单转子**公式 $B_g=B_r/(1+(g+t_{PCB})/h_m)$，只含"一个气隙 + 整块 PCB"，对应的是另一种"单转子 + 回流铁"的电机，给出 0.179 T（偏低 42 %）；"只算半个 PCB"的经验修正给 0.306 T，也**不是**双转子拓扑的正确解。

单极面积 $A_p=\pi(D_o^2-D_i^2)/(2\cdot2p)=2.45\times10^{-5}\ \mathrm{m^2}$，

$$\Phi_p=B_gA_p,\qquad K_t=\tfrac32\,p\,N_{ph}\,\Phi_p$$

$N_{ph}=48\times3\times3/2=216$（推断，见 §1.1）⇒ $K_t=12.28$ mNm/A（双转子 1-D 磁路）；换用 2D FEA 的 $B_g=0.3766$ T ⇒ $K_t=14.95$ mNm/A。

## 4. 验证结果与发现的问题

### 4.1 磁路 vs 2D FEA（自洽性）

| 模型 | $B_g$ | 说明 |
|---|---|---|
| 旧 1-D 单转子公式 | 0.179 T | 拓扑错误（只有一个气隙 + 整块 PCB），偏低 42 %，仅作历史值保留 |
| **1-D 双转子（TORUS，当前）** | **0.3093 T** | 2 个磁钢串联 + 2 个气隙 + 1 块 PCB |
| 2D FEA（周期边界修正后） | **0.3766 T** | 切向–轴向切片，160×120 网格 |

**2D 比双转子 1-D 磁路高 21.8 %**（0.3766/0.3093）。方向合理：2D 切片是"无限深"近似（不含 3D 端部漏磁），磁钢又是有限极弧，极间漏磁与边缘效应都会进入气隙平均磁密；而 1-D 磁路把气隙磁密当作均匀值、完全忽略漏磁，因此偏低。这个 **+21.8 %** 就作为 1-D 磁路的模型不确定度。$\Phi_p$ 也相应有两个口径：`flux_per_pole_fem_Wb = 9.2284e-6`、`flux_per_pole_circuit_Wb = 7.5792e-6`（旧的单一 `flux_per_pole_Wb` 已拆开，避免再把 4.39e-6 / 9.29e-6 混用）。

> **基准必须写清**：旧文的"2D 与磁路差 24 %"是 $(0.379-0.306)/0.306=+23.9\%$，基准是"半 PCB 对称"的经验值 0.306 T；而旧文表格里存的磁路值 0.179 T 与 2D 的比值是 **+111 %**。两个都不是当前双转子口径，引用时必须写明。

> **这是工具链的局限，不是论文的问题**：单定子 AFPM 的场分析本质需要 **3D**（或带径向回流路径的轴对称模型，但轴对称又无法表达交替极性）。本报告据此把 2D 结果降级为"定性场图"，定量只采用双转子 1-D 磁路模型。

### 4.2 $K_t$ 对标

| 来源 | $K_t$ |
|---|---|
| 实测 | 32.0 mNm/A |
| 表 I 匝数 216 + 双转子 1-D 磁路（0.3093 T） | 12.28 mNm/A |
| 表 I 匝数 216 + 2D FEA 磁密（0.3766 T） | 14.95 mNm/A |
| 反推所需匝数（磁路基准） | **562.9** |
| 反推所需匝数（FEA 基准） | **462.3** |

差距 2.1–2.6 倍（**−53.3 %** / **−61.6 %**）。可能的解释（论文未给数据，无法判定）：
1. 每相串联匝数不是 216——216 本身是推断值（见 §1.1），按它只能得到 12–15 mNm/A；要 32 mNm/A 需约 **462–563 匝**；
2. 磁钢更厚或 $B_r$ 更高（$h_m=3$ mm、$B_r=1.4$ T 可把 $B_g$ 抬到 ~0.6 T）——论文未给磁钢厚度与牌号；
3. 1-D 磁路与 2D 切片都缺铁芯磁阻、极弧系数与端部漏磁——论文未给铁芯材料与厚度。

**判定：❌ 未通过**——用论文现有参数无法复现实测 $K_t$：以 FEA 磁密为基准差 **53.3 %**，以双转子 1-D 磁路为基准差 **61.6 %**；**两套基准下"论文参数无法闭合 $K_t=32$"的结论一致**，已如实记录、没有用拟合去凑。

### 4.3 相电阻对标

$R=\rho_{Cu}N_{ph}l_{turn}/A$，取 $l_{turn}=2(R_o-R_i)+2\pi r_m/9=16.5$ mm、$A=0.36\times0.06$ mm²：

$$R=\frac{1.72\times10^{-8}\times216\times0.0165}{2.16\times10^{-8}}=2.84\ \Omega$$

> 0.06 mm 取自论文表 I 的 "Thickness per PCB layer (mm)"，原文**没有说明**它是铜厚还是层间距/介质厚度；本报告把它当作铜厚使用，这是**解释**而不是论文的明确数据。

实测 4.70 Ω，低 40%。差异可由端接铜箔、过孔、以及每匝实际长度更大解释（要把 2.84 提到 4.70，$l_{turn}$ 需约 27 mm）。

**判定：⚠️ 同量级，未精确复现。**

### 4.4 堵转点自洽性

$158\ \text{mNm}/5.95\ \text{A}=26.6$ mNm/A，低于小电流下的 32 mNm/A——符合磁路饱和的物理规律，**这一条通过**。

## 6. 局限与下一步

| 项 | 状态 | 说明 |
|---|---|---|
| 3D 电磁场 | ❌ 缺 | 单定子 AFPM 必须 3D；可用 FEMM(轴对称近似)/GetDP/自研 3D 棱边元 |
| 磁钢厚度 / Br | ❌ 论文未给 | 已用显式假设，$K_t$ 因此无法闭合 |
| 绕组拓扑 | ❌ 论文未给 | 216 vs 462–563 匝，需原理图或层叠图 |
| 铁损 / 铜损 | ❌ 未算 | 需要 $B(t)$ 时域波形与材料损耗曲线 |
| 退磁校核 | ❌ 未算 | 需要磁钢内禀曲线与最恶劣工况 |
| 转矩脉动 / 齿槽 | ❌ 未算 | 需要转子位置扫描（3D 或 2D 多切片） |
