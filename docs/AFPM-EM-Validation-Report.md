## 2. 工具链新增能力：自研 2D 磁静场求解器

原工具链（build123d / gmsh / CalculiX / PyVista）**没有电磁求解器**。本轮新增：

- **公式**：磁标量势 $\nabla\cdot(\mu\nabla\varphi)=\nabla\cdot(\mu_0\mathbf M)$，$B=-\mu\nabla\varphi+\mu_0\mathbf M$
- **离散**：线性三角形单元，标准刚度阵 $\int\mu\nabla N_i\cdot\nabla N_j$，磁钢以 $\int\mu_0\mathbf M\cdot\nabla N_i$ 进入右端
- **边界**：切向周期（极距）、PCB 中面 Neumann 对称、外表面 $\varphi=0$
- **实现**：numpy 装配 + scipy 稀疏求解，网格 160×120（19,200 个四边形 → 38,400 个三角形单元），求解 < 2 s
- **域**：平均半径处展开成"切向 x — 轴向 y"的平面，一个极距

旧半模型的结果（**已被 §4.1b 的全叠层模型取代**）：PCB 中面平均 $|B_y|=0.3766$ T（周期边界修正后）；全叠层 GetDP 给出气隙 0.430 T、层平均线圈磁通 0.077 T。

> **周期边界 bug（2026-11 修复）**：旧版 `solve_2d` 把右边界直接钳成 $\varphi=0$，而不是与左边界相等——$\varphi(0)-\varphi(L_x)\approx819$ A，两个半极区的 $|B_y|$ 相差 2.9 倍，**场图不是周期的，不能用作定量依据**。修复方式是在装配前把 slave 自由度合并到 master；修复后 $B_g$ 仅变 **−0.6 %**（0.3790 → 0.3766 T）：标量结论不变，但**修复前的场图不可信**；当前 `viz/field_2d.png` 等图已用修复后版本重绘。注意 0.3766 T 仍是半模型的**中面**磁密，不是线圈磁通（见 §4.1b）。

## 3. 解析磁路模型

采用**双转子（TORUS）拓扑**：两个转子磁钢串联，驱动磁通从两侧穿过同一块 PCB，回路里有 **2 个磁钢 + 2 个气隙 + 1 块 PCB**：

$$B_g=\frac{2B_r h_m}{2h_m/\mu_r+2g+t_{PCB}},\qquad 2g+t_{PCB}=2\times0.25+6.0=6.5\ \text{mm}$$

$h_m=1$ mm、$B_r=1.3$ T、$\mu_r=1.05$ ⇒ $B_g=0.3093$ T。

> 旧版用的是**单转子**公式 $B_g=B_r/(1+(g+t_{PCB})/h_m)$，只含"一个气隙 + 整块 PCB"，对应的是另一种"单转子 + 回流铁"的电机，给出 0.179 T（偏低 42 %）；"只算半个 PCB"的经验修正给 0.306 T，也**不是**双转子拓扑的正确解。

单极面积 $A_p=\pi(D_o^2-D_i^2)/(2\cdot2p)=2.45\times10^{-5}\ \mathrm{m^2}$，

$$\Phi_p=B_gA_p,\qquad K_t=\tfrac32\,p\,N_{ph}\,\Phi_p$$

$N_{ph}=48\times3\times3/2=216$（推断，见 §1.1）⇒ $K_t=12.28$ mNm/A（双转子 1-D 磁路）；换用旧半模型 2D 的 $B_g=0.3766$ T ⇒ $K_t=14.95$ mNm/A（**该半模型值已被 §4.1b 取代，全叠层为 3.07**）。

## 4. 验证结果与发现的问题

### 4.1 磁路 vs 2D FEA（自洽性）

| 模型 | $B_g$ | 说明 |
|---|---|---|
| 旧 1-D 单转子公式 | 0.179 T | 拓扑错误（只有一个气隙 + 整块 PCB），偏低 42 %，仅作历史值保留 |
| **1-D 双转子（TORUS，当前）** | **0.3093 T** | 2 个磁钢串联 + 2 个气隙 + 1 块 PCB |
| 旧半模型 2D（周期边界修正后） | **0.3766 T** | 切向–轴向**半**切片，160×120 网格；中面强加对称条件，已被 §4.1b 取代 |

**0.3766 T 是旧半模型的 PCB 中面值，不是线圈磁通**：半模型在 PCB 中面强加对称条件，等效于把穿越 PCB 的磁通人为固定。§4.1b 的全叠层 GetDP 模型给出气隙 0.430 T、**层平均线圈磁通 0.077 T**，并表明 6 mm PCB 的极间漏磁占主导。因此旧的 0.3766 T 与 "+21.8 %" 不再作为 2D 结论，只保留为"半模型中面对称假设导致偏差"的证据；$\Phi_p$ 的两个旧口径（`flux_per_pole_fem_Wb = 9.2284e-6`、`flux_per_pole_circuit_Wb = 7.5792e-6`）也已被 §4.1b 的层平均 $1.90\times10^{-6}$ Wb 取代。

> **基准必须写清**：旧文的"2D 与磁路差 24 %"是 $(0.379-0.306)/0.306=+23.9\%$，基准是"半 PCB 对称"的经验值 0.306 T；而旧文表格里存的磁路值 0.179 T 与 2D 的比值是 **+111 %**。两个都不是当前双转子口径，引用时必须写明。

> **这是工具链的局限，也是本次修正的重点**：单定子 AFPM 的场分析本质需要 **3D**；2D 全叠层（§4.1b）已能给出强极间漏磁的定量证据，但径向回流与端部漏磁仍需 3D 最终裁决。旧半模型的 2D 结果因此不再用于定量结论。

### 4.1b GetDP 全叠层 2D 复核（2026-11，取代半模型）

旧 `afpm_model.py` 的半模型在 PCB 中面强加对称条件（自然 Neumann / 或 Dirichlet），这等于
**人为规定**穿越 PCB 的磁通；真实 TORUS 的磁通路径与极间漏磁都被这个假设掩盖。为此新增
`scripts/afpm_getdp.py`：Gmsh 生成**全叠层**（上下转子磁钢 + 背铁、PCB、两个气隙）的**材料界面
贴合**网格（气隙 3 层、磁钢 10 层、PCB 每半 8 层、背铁 6 层），GetDP 3.2.0 用 $A_z$ 表述求解：

$$\nu\,\nabla A_z \cdot \nabla w + h_c \cdot \nabla w = 0,\qquad h_c=-B_r/(\mu_0\mu_r)$$

域取**一个极**（从一块磁钢中心到相邻反极性磁钢中心），两端 $B_x=0$（对称面），故 $A_z=0$ 是精确边界，
不需要周期约束/规范固定。外边界自然 Neumann。磁化只加在磁钢区（修正了旧求解器把背铁也磁化的 bug）。

**验证**：把极距放大 10 倍（漏磁可忽略的 1-D 极限），气隙 $|B_y|$ = **0.3116 T**，与双转子 1-D
磁路 **0.3093 T** 相差 **+0.7 %**——表述、$h_c$ 符号、网格与单位都正确。

**真实几何**（$R_o=9.5$、$R_i=3.5$ mm、10 极、$h_m=1$ mm、$B_r=1.3$ T、$\mu_r=1.05$、极弧=1）：

| 量 | 值 |
|---|---|
| 气隙 $\overline{|B_y|}$ | **0.430 T** |
| PCB 中面 $\overline{|B_y|}$ | **0.065 T** |
| PCB 近磁钢面（$y=3.0$ mm） $\overline{|B_y|}$ | **0.376 T** |
| 层平均每极磁通（$z=0\to 3$ mm 平均） | **$1.90\times10^{-6}$ Wb**（$\hat B_\mathrm{pole}=0.077$ T） |
| $K_t$ @ 216 匝（均值半径 / 5 切片） | **3.07 / 3.15 mNm/A** |

**结论**：轴向磁通在 6 mm PCB 内从表面 0.38 T 衰减到中面 0.065 T；6 mm PCB 厚度与
$2\pi R/10=4.08$ mm 的极距相比太大，**同转子相邻极经 PCB 的极间漏磁占主导**（层平均线圈
磁通仅为 1-D 磁路的约 22 %）。旧半模型 0.3766 T 的"2D 磁密"不是线圈磁通，而是被中面对称
条件抬高的结果；旧 $K_t=14.95$ 因此高估约 5 倍。代码/数据：`scripts/afpm_getdp.py`、
`results/afpm-pcb-motor/getdp2d/{result,multislice}.json`。

**B-H 检查（一步割线）**：线性解给出的背铁平均 $|B|\approx0.57$ T；FeSi 曲线在该点
$\mu_r\approx6\times10^3$，取 $\mu_r=5000$ 重解，$K_t$ 3.083 → **3.082 mNm/A**（<0.1 %）。
背铁远未饱和，B-H 不改变漏磁结论。实现为**全局割线**（`--bh`：线性解 → 背铁 $B$ → 有效
$\mu_r$ → 重解），不是局部 Newton；由 $\mu_r$ 在低场段很平，单步割线已足够。

**3D 一极对（展开 slab）**：把同一 r-z 叠层沿周向展开成**一极对**（$x=0..2P$），y/z 加
1 mm 空气边界并在外边界设 $\phi=0$；无自由电流，GetDP 用**标量势** $\phi$ 求解
（$B=-\mu\nabla\phi-\mu h_c$），x 两端为磁钢中心对称面（Neumann）。216 匝：
$K_t=2.84$ mNm/A，比 2D 5 切片 3.15 低 **10 %**（径向端部漏磁）。注意这是**展开 slab**，
极距沿周向不变；真正的**环形扇区**（极距随半径变化）仍是下一步。代码：
`scripts/afpm_getdp3d.py`、`results/afpm-pcb-motor/getdp3d/result.json`。

**3D 环形扇区（最终几何）**：`scripts/afpm_getdp3d_sector.py` 用 OCC 部分圆柱（外减内）
构造**一个极的 36° 环形扇区**（$r=3.5..9.5$ mm，径向/轴向各 1 mm 空气，`fragment` 共形），
标量势 $\phi$，外空气边界 $\phi=0$，两个径向对称面 Neumann。磁钢为两个 18° 角向半环，
极距 $2\pi r/10$ 随半径真实变化（内半径 2.2 mm、外半径 6.0 mm）。网格收敛：
$h=0.6/0.35/0.30$ mm → $K_t=2.45/2.61/2.60$ mNm/A，取 **2.60**（每极磁通
$1.60\times10^{-6}$ Wb）。它比 2D 5 切片 3.15 低 **17 %**、比 3D slab 2.84 低 8 %：
内半径极距小、漏磁更强，且磁钢角向宽度随半径变化——这正是展开 slab 缺的几何。
反推匝数约 **2700**。代码/数据：`scripts/afpm_getdp3d_sector.py`、
`results/afpm-pcb-motor/getdp3d-sector/result.json`。

### 4.2 $K_t$ 对标

| 来源 | $K_t$ |
|---|---|
| 实测 | 32.0 mNm/A |
| 表 I 匝数 216 + 双转子 1-D 磁路（0.3093 T） | 12.28 mNm/A |
| 216 匝 + 旧半模型 2D（0.3766 T） | 14.95 mNm/A（**已被 §4.1b 取代**） |
| **216 匝 + GetDP 全叠层 2D（层平均）** | **3.07 mNm/A（均值半径）/ 3.15（5 切片）** |
| 反推所需匝数（1-D 磁路 / 旧半模型） | **562.9 / 462.3** |
| **反推所需匝数（GetDP 全叠层）** | **≈2200** |

差距约 **10 倍**（**−90 %**）。可能的解释（论文未给数据，无法判定）：
1. 每相串联匝数不是 216——216 本身是推断值（见 §1.1）；按 GetDP 全叠层场要 32 mNm/A 需约 **2200 匝**；
2. PCB 实际有效厚度/叠层与"6 mm 单块"不同（例如多块 PCB 串联、有效磁路厚度更薄）——论文的 "48 layers / 3 PCBs in series" 本身两义；
3. 磁钢更厚/$B_r$ 更高、极弧/拓扑不同——论文未给磁钢厚度与牌号；
4. 上述 2D 全叠层模型仍是**单切片 + 线性铁**，需要 3D/多切片 + B-H 才能最终裁决。

**判定：❌ 未复现，且列为 not verifiable**——论文参数集在标准 TORUS 解释下无法闭合实测 $K_t$
（GetDP 全叠层差约 90 %，1-D 磁路差 62 %）；但差距已大到不能归因于单一"匝数"缺项，必须
补论文缺失的磁钢/PCB/绕组数据并用 3D 模型才能判定是论文数据问题还是模型解释问题。
**不再使用旧半模型的 −53 % 作为结论**；旧值只作为"半模型中面对称假设导致的偏差"保留。

### 4.3 相电阻对标

$R=\rho_{Cu}N_{ph}l_{turn}/A$，取 $l_{turn}=2(R_o-R_i)+2\pi r_m/9=16.5$ mm、$A=0.36\times0.06$ mm²：

$$R=\frac{1.72\times10^{-8}\times216\times0.0165}{2.16\times10^{-8}}=2.84\ \Omega$$

> 0.06 mm 取自论文表 I 的 "Thickness per PCB layer (mm)"，原文**没有说明**它是铜厚还是层间距/介质厚度；本报告把它当作铜厚使用，这是**解释**而不是论文的明确数据。

实测 4.70 Ω，低 40%。差异可由端接铜箔、过孔、以及每匝实际长度更大解释（要把 2.84 提到 4.70，$l_{turn}$ 需约 27 mm）。

**判定：⚠️ 同量级，未精确复现。**

### 4.4 堵转点自洽性

$158\ \text{mNm}/5.95\ \text{A}=26.6$ mNm/A，低于小电流下的 32 mNm/A——符合磁路饱和的物理规律，**这一条通过**。

| 磁钢厚度 / Br | ❌ 论文未给 | 已用显式假设，$K_t$ 因此无法闭合 |
| 绕组拓扑 | ❌ 论文未给 | 216 vs 462–563 匝，需原理图或层叠图 |
| 铁损 / 铜损 | ❌ 未算 | 需要 $B(t)$ 时域波形与材料损耗曲线 |
| 退磁校核 | ❌ 未算 | 需要磁钢内禀曲线与最恶劣工况 |
| 转矩脉动 / 齿槽 | ❌ 未算 | 需要转子位置扫描（3D 或 2D 多切片） |
